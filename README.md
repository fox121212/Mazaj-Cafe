# Mazaj Cafe

A website for Mazaj Cafe, a small specialty coffee shop in Beirut. Built with React and React Router.

## Pages
- **Home**: welcome section and house favourites
- **Menu**: drinks and pastries with prices
- **About**: the cafe's story
- **Contact**: how to reach us

## Run it
```
npm install
npm start
```
Then open http://localhost:3000
